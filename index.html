VeriLens

AI-Powered Multimodal Document Integrity Engine for Real-Time Forgery Detection in Banking Underwriting
Hackathon: SuRaksha by Canara Bank  ·  Theme: Real-time Anomaly Detection  ·  Track: AI / FinTech Security

🚨 The Problem

Document fraud in Indian banking — forged land records, fabricated income statements, tampered legal agreements — costs the sector an estimated ₹7,000+ crore annually. Yet underwriting still relies on manual document review: slow, inconsistent, and blind to sophisticated forgery.

Loan officers spend 3–4 hours per application on document checks — and still miss 30–40% of frauds that are only caught post-disbursement. No existing system combines computer vision, document AI, graph intelligence, and government API validation into a single underwriting pipeline.

The gap: Current tools either do OCR + rule checks (misses pixel-level tampering) or image analysis only (misses semantic fraud). No system reconstructs HOW a fraud was committed or learns from evolving fraud patterns.

💡 Our Solution

VeriLens is an 8-module AI system that analyzes any uploaded banking document across four detection layers simultaneously, then runs four exclusive intelligence modules that no existing Indian banking system has built — delivering a complete Underwriter Intelligence Report in under 60 seconds.

🔬 Module 1–4: Core Detection Engine

Four detection layers run in parallel on every document upload:

LAYER 01
Pixel Forensics
EfficientNet-B4 (fine-tuned) · EXIF analysis
Copy-paste artifactsFont inconsistencyNoise pattern breaksMetadata mismatchEXIF anomalies

Analyzes the raw document image for tampering invisible to the human eye — different noise patterns where content was pasted, font rendering inconsistencies, pixel-level signature cloning.

LAYER 02
Semantic Cross-Verification
LayoutLMv3 (Microsoft) · spaCy NER · Custom financial entity extractor
Internal consistencyDate logic checksAmount matchingAuthority validationName resolution

Extracts all structured data from the document and checks internal consistency — amount on page 1 vs repayment schedule on page 3, stamp date vs authority establishment date, borrower name vs PAN record.

LAYER 03
Knowledge Graph Anomaly Detection
Neo4j · NetworkX · Graph ML algorithms
Dual ownership detectionCircular chainsBorrower = guarantorShell entity patternsGraph traversal

Maps all document entities into a knowledge graph and detects impossible relationships — same property sold to two people, circular ownership chains between related entities, guarantors who are also borrowers.

LAYER 04
Public Record Cross-Referencing
MCA21 API · CERSAI API · Land Registry Portals
Registration verifyOwnership checkLien & charge statusDirector lookupLive API calls

Validates document claims against live government databases — does this registration number exist? Does this person own this property? Is there an existing lien on this asset?

⚡ Module 5–8: Exclusive Intelligence Modules

These are what make VeriLens unique. No existing Indian banking fraud detection system combines these four capabilities. Each one alone would be novel. Together, they represent a national-level fraud intelligence infrastructure.
EXCLUSIVE
MODULE 05
Fraud Narrative Reconstruction
LLM chain-of-thought · SHAP attribution · Timeline analysis
HOW fraud was committedStep-by-step storyTechnique identificationTimeline reconstruction

Instead of just flagging fraud, VeriLens reconstructs the exact method used — like a forensic investigator writing a case report. The LLM synthesizes findings from all 4 layers into a human-readable narrative.

Example output: "The signature on page 4 appears to have been digitally cloned from a different document — pixel noise patterns diverge from the surrounding page. Metadata indicates the file was modified 3 days after the notarization date on page 1. The ownership chain shows a circular transfer between Entity A → Entity B → Entity A, suggesting shell entity involvement."
EXCLUSIVE
MODULE 06
Forgery Evolution Graph
Temporal clustering · HDBSCAN · Graph ML · Time-series pattern analysis
Pattern tracking over timeEmerging tactic detectionCross-case clusteringFraud threat intel

The system learns how forgery techniques evolve. As more documents are analyzed, it clusters similar fraud patterns, tracks how new tactics emerge, and generates a Fraud Threat Intelligence Feed — alertable across bank branches. This transforms VeriLens from a document checker into a national fraud observatory.

EXCLUSIVE
MODULE 07
Synthetic Fraud Simulation Engine
CTGAN · Adversarial generation · Diffusion-based document synthesis
Generates synthetic forgeriesAdversarial stress testingSelf-improving training loopRed-team simulation

VeriLens generates its own synthetic forged documents to continuously retrain and stress-test itself. The system acts as both attacker (generating new forgery tactics) and defender (improving detection). This makes VeriLens self-improving — the only fraud detection system in India that gets better without needing new real fraud data.

EXCLUSIVE
MODULE 08
Trust DNA Score
Multi-axis ensemble · 6-dimensional document profiling
Tamper probabilityEntity reliabilityMetadata trustOwnership consistencyAnomaly densityLegal authenticity

Instead of a single fraud score, every document receives a 6-axis Trust DNA — a fingerprint of its trustworthiness across different dimensions. Like a credit score, but for document integrity. Underwriters can see exactly which dimension is failing and why.
